# Privacy Policy

Ser2Net does not transfer information to networked systems unless specifically
requested by the user or the person installing or operating it.

Ser2Net is a configurable serial and gensio endpoint bridge. It opens and
connects only the endpoints configured by the operator, such as local serial
ports, TCP ports, or other gensio endpoints.

The Windows tray manager and service wrapper store configuration and logs on
the local machine under `C:\ProgramData\Ser2Net` when installed. Portable builds
store configuration relative to the portable folder when run with `--root`.

Ser2Net does not include telemetry, analytics, advertising, or automatic crash
report upload.

Users are responsible for protecting any credentials, keys, certificates, or
endpoint addresses they place in Ser2Net configuration files.
